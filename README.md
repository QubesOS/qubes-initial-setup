# Qubes Initial Setup

Qubes packaging of `initial-setup`, the first-boot configuration utility built on Anaconda, part of [Qubes OS](https://www.qubes-os.org). It runs on the first boot after installation and guides the user through the final configuration steps. This repository builds the upstream utility with a small set of Qubes patches (one of them re-enables Anaconda addon modules); the Qubes-specific first-boot setup is provided by a separate addon, not by this repository.

See the [installation guide](https://www.qubes-os.org/doc/installation-guide/) for how first boot fits into setting up Qubes OS.
